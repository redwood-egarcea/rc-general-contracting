# RC monogram concept

Created with the built-in image-generation tool. Reference: `src/assets/logo.jpg`, the existing company logo. This concept keeps RC and the roofline and removes the remaining lettering and decorative elements. The PNG has a transparent background. It is a raster concept, not a vector master.

## Generation prompt

Use case: logo-brand. Redesign the attached RC General Contracting logo into a single exceptionally refined minimalist brand mark for a residential and commercial construction company. The attachment is the existing logo and identity reference. Keep only the letters R and C and a very subtle architectural roofline, redesigned completely with precise geometric custom lettering. Remove ALL company wording, slogan, tree, window, chimney and waves. Exact visible characters: RC. No other text at all. Create a compact, optically balanced monogram: bold clean upright geometric R and C with generous open counters, a distinctive purposeful relationship between the two letters, one simple pitched roof stroke integrated into the top of the composition. It should feel like a carefully designed architectural studio identity, confident and quiet, legible at small website-header sizes and on workwear. Avoid a stock house pictogram with text underneath; the roof and letters must read as one unified mark. Flat single-colour dark blue ink #172d39. True transparent background, crisp vector-like edges, no shadows, gradients, textures, 3D, borders, decorative badges, mockups or presentation labels. Produce one large centered logo on a square transparent canvas with ample clean padding. This is an isolated logo asset, not a contact sheet or web page.

## Approved website use

The owner approved applying this mark to the website on 25 September 2026. The unchanged source is `src/assets/rc-monogram.png`. Astro generates WebP header/footer variants, a 96px PNG favicon, a 180px touch icon, and a 512px PNG for structured data. UI cropping removes only transparent canvas padding; the complete square is used for icons and search metadata. Dark mode uses the same silhouette in white through CSS. The earlier logo remains archived as `src/assets/logo.jpg`.
